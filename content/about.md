## 为什么做这个站

模拟电路的学习资料往往散落在三种地方：聊天记录里的推导、收藏夹里的网页、以及某个再也没打开过的笔记软件。内容越多，越难找到“上次那个讲折叠共源共栅的图”。

这个站点的目标很朴素：**把零散但有用的内容收进一个可读、可检索、可分享的地方**。它不追求做成一个完整的课程平台，而是更像一本持续生长的实验笔记。

## 三条设计原则

### 内容是普通文件

笔记是 Markdown，实验是独立 HTML。没有数据库，没有私有格式，也没有必须联网才能打开的后台。任何时候，你都可以把这些文件复制到另一个地方继续用。

### 导航是自动的

新增一篇笔记时，只需要放对文件夹并写少量元信息。目录、上一页/下一页、阅读时间、搜索索引、Markdown 下载链接会自动生成。实验页同理，只需要一个可选的 `.meta.json`。

### AI 是助手，不是裁判

这个站点里的内容大量由 AI 辅助整理。AI 擅长搭框架、补术语、把一段推导写顺；但它也会自信地写错，尤其是在工艺参数、稳定性判断和版图效应上。因此：

- 标注了“AI 辅助”的页面需要人工复核。
- 关键公式尽量给出假设和适用条件。
- 设计案例的数值只用于演示方法，不代表真实 PDK 或实测结果。
- 发现错误时，优先修改源 Markdown，而不是只改渲染后的页面。

## 技术实现

| 层 | 选择 | 原因 |
| --- | --- | --- |
| 内容 | Markdown + 独立 HTML | 可移植、可由 AI 直接生成 |
| 构建 | Node.js 静态生成 | 无运行时框架，部署简单 |
| 公式 | KaTeX（本地资源） | 不依赖外部 CDN |
| 搜索 | 构建时生成 JSON 索引 | 纯前端、无需服务端 |
| 部署 | GitHub Pages / 任意静态托管 | 推送即更新，可绑定自定义域名 |

构建脚本会扫描 `content/` 和 `labs/`，生成静态页面、目录、搜索索引和上一页/下一页，并把 KaTeX 字体一起打包。页面不依赖外部字体或 CDN，断网时仍可阅读。

## 内容边界与许可

- 本站原创的站点代码采用 **MIT** 许可。
- 除页面内另有说明外，笔记内容采用 **CC BY-SA 4.0** 许可。
- 从其他来源导入的内容保留其原有许可。例如 OTA 设计指南标注为“仅供学习与研究”，不应直接按 CC BY-SA 再分发。
- 所有设计示例均为教学假设，不构成可直接用于流片或生产的工程交付。

## 下一步

这个站点最重要的功能不是“看起来完整”，而是**你下周还会往里放东西**。如果只能做一件事，就从[添加内容指南](how-to-add.html)开始：放一篇最近真正想弄懂的主题，而不是先补一个漂亮的分类。

::: note 一句提醒
如果某篇笔记放了三个月都没有再打开，它可能不是“资料不够”，而是没有和你的问题连起来。删掉、重写、或把它压缩成一张卡片，都比继续收藏更有用。
:::

::: note 先读这一段
模拟电路不是“把公式背完”就能学会的科目。真正需要建立的是三件事：**数量级直觉**、**从电路到小信号模型的翻译能力**，以及**用仿真和测量校准判断的习惯**。这份路线按这三件事组织，而不是按教材章节罗列。
:::

## 先确认你现在的起点

不同起点的读法不一样。下面这张表不是能力评级，只是帮你决定从哪里切入。

| 你现在的状态 | 建议起点 | 暂时可以跳过 |
| --- | --- | --- |
| 学过电路分析，但没碰过晶体管 | 半导体基础 → 单管直流偏置 | 复杂运放指标 |
| 会算共源、共射，但一看到完整电路就乱 | 小信号模型 → 电流镜 → 差分对 | 版图与可靠性 |
| 做过课程设计，想系统补模拟 IC | 频率响应 → 噪声 → OTA 设计 | 器件物理的量子细节 |
| 主要做数字/系统，需要和模拟团队对话 | 信号链 → 采样与量化 → 行为级建模 | 手工画版图 |

::: tip 一个判断标准
如果你能对一个陌生电路说出“它的偏置从哪里来、信号从哪里进、负载是什么、主要极点大概在哪”，就已经跨过了入门阶段。剩下的精度可以慢慢补。
:::

## 一条六阶段的路线

### 0. 数学与工具：先够用，再补全

**目标**：能读懂复频域表达，能动手算，也能把结果画出来。

- 电路分析：节点法、戴维南/诺顿、受控源、叠加定理。
- 数学：微积分、复数、拉普拉斯变换、一阶/二阶系统。
- 工具：一个 SPICE 仿真器、Python 或 MATLAB、能画 Bode 图的工具。
- 习惯：所有计算都带单位；所有近似都写下成立条件。

不必先把数学全部学完。遇到极点、留数或矩阵时再回头补，通常更有效。

### 1. 器件与单管：把物理翻译成模型

**目标**：知道 MOS/BJT 在什么区域、由什么量控制、小信号参数从哪里来。

- PN 结、势垒、耗尽层与结电容。
- MOS 的阈值、反型、沟道长度调制、体效应。
- 大信号平方律与完整 I-V 的关系。
- 跨导 $g_m$、输出电阻 $r_o$、本征增益 $g_m r_o$。
- BJT 的 $g_m=I_C/V_T$、$r_\pi=\beta/g_m$。

这一阶段最重要的不是背公式，而是能回答：**“如果我把偏置电流加倍，$g_m$ 和 $r_o$ 各自怎么变？”**

### 2. 单管与差分：从一块砖到一面墙

**目标**：能独立设计一个偏置合理、增益可算、摆幅够用的基本级。

- 共源/共射、共栅/共基、源极/射极跟随器。
- 电流镜、有源负载、 cascode 的用途。
- 差分对的差模与共模半电路。
- 尾电流源、共模输入范围、输出摆幅。
- 增益、输入/输出阻抗的手算与仿真对照。

练习时不要只算增益。同时算一遍：静态工作点是否在饱和区？输出还能摆多少伏？功耗是多少？

### 3. 频率响应与反馈：从“能放大”到“能稳定工作”

**目标**：能定位主极点，判断稳定性，并解释补偿为什么有效。

- 极点、零点、时间常数与 Bode 图。
- 主极点近似、增益带宽积、单位增益频率。
- 相位裕度、阶跃响应的振铃与建立时间。
- 负反馈的四种基本组态。
- Miller 补偿、前馈零点、负载电容的影响。
- 噪声与带宽的交换关系。

::: insight 先问“谁是主极点”
大多数稳定性问题，不是公式不够复杂，而是没有先找出**最快的那个节点**和**最大的那个电容**。在动手补偿之前，先画一张节点—电容表。
:::

### 4. 系统模块：把单级组成完整系统

**目标**：理解一个完整模拟前端的指标如何互相牵制。

- 运算放大器：增益、GBW、压摆率、噪声、失调、共模范围。
- 电压基准与偏置电路。
- LDO 与电源抑制。
- 采样保持、开关电容与抗混叠滤波。
- ADC/DAC 的基本架构与指标：SNR、SNDR、SFDR、ENOB。
- AFE 信号链：从传感器到数字输出。

到了这里，应该开始习惯用“指标预算”而不是“单点最优”来做设计。

### 5. 设计与验证：把推导变成可复核的工程

**目标**：能从一个规格表出发，完成尺寸计算、仿真验证和迭代记录。

- 工艺参数与 PDK：$\mu C_{ox}$、$V_{TH}$、$\lambda$、$C_{ox}$、匹配参数。
- $g_m/I_D$ 方法：从弱反型到强反型的连续设计视角。
- 噪声积分、输入参考噪声、积分噪声与 ADC 分辨率的关系。
- PVT corners、蒙特卡洛、失配与版图对称性。
- 行为级模型：SystemVerilog/Verilog-AMS、事件驱动仿真。
- 文档：每个设计决策的理由，比最后的数字更重要。

这一阶段最值得建立的工具，是一个自己的**设计检查表**。本站的 OTA 笔记与 AFE 建模教程可以作为两个样本。

## 每篇笔记怎么读

1. **先读结论和适用条件**：不要一上来就抄推导。先知道这个公式在什么假设下成立。
2. **遮住过程自己推一遍**：哪怕只推关键的两步，也比被动阅读有效。
3. **代入一组数量级**：例如 $I_D=10\,\mu A$、$g_m=100\,\mu S$、$r_o=100\,k\Omega$，看看结果是否合理。
4. **用仿真验证一个点**：不要为了证明自己对而仿真，要为了找到自己错在哪里而仿真。
5. **写一段自己的话**：能用三句话向别人解释，才算真的掌握。

## 一个 90 分钟的学习循环

| 时间 | 动作 | 产出 |
| --- | --- | --- |
| 0–15 min | 回顾上一节，合上书复述关键结论 | 一张空白纸上的模型 |
| 15–45 min | 读新内容，只记问题和推导卡点 | 3–5 个具体问题 |
| 45–70 min | 手算一个例题，再用 SPICE 对照 | 一组可解释的偏差 |
| 70–85 min | 把结论压缩成 5 条以内 | 自己的速查卡 |
| 85–90 min | 安排下一次复习 | 一个明确起点 |

## 自检：什么时候可以进入下一阶段

- [ ] 我能不看笔记画出 MOS 的小信号模型，并说明每个参数的来源。
- [ ] 我能从一个偏置电流出发，估算 $g_m$、$r_o$ 和本征增益。
- [ ] 我能判断一个单管电路是否处于饱和区，并算出输出摆幅。
- [ ] 我能从节点电容和电阻估算主极点，并解释相位裕度。
- [ ] 我能把输入参考噪声与系统 SNR 做一次粗略预算。
- [ ] 我能写出一个可运行的 AFE 行为级模型，而不只是画框图。
- [ ] 我能说清楚自己的设计在哪些 corner 下最危险。

不必全部打勾才开始下一阶段。**至少有一项能讲清楚，就可以继续往前走，同时把没掌握的留在复习清单里。**

折叠共源共栅（folded cascode, FC）是开关电容电路与混合信号前端中最常用的单级 OTA 之一。它用大约两倍的偏置电流，换来更大的输出摆幅、更宽的输入共模范围，以及不需要 Miller 补偿的单极点行为。但它也有三个常被低估的代价：输出电阻往往被输出端的简单电流源限制；折叠支路的 2ID 电流源带来额外噪声；headroom 在电源轨之间被逐层吃掉。本文把这三件事讲清楚，并给出一套可以直接落地的手算与迭代流程。

关于数据与仿真的声明：本文不包含任何来自具体 PDK 的模型参数、仿真波形或硅实测数据。第 4 章的 μCox、VTH、VA 等数值是为演示手算流程而设定的假设值，不代表任何代工厂工艺。真实设计必须替换为 PDK 的 gm/ID 查找表、Cgg/Cdd 寄生、失配模型与 corner 数据。文中所有“结果”都是手算估计，必须用 SPICE 验证。

十条结论
  1. 拓扑。标准 9 管 FC = 输入对（2）+ 尾电流源（1）+ 折叠电流源（2）+ 共栅管（2）+ 输出电流源（2）。每个折叠节点上，折叠源提供 2ID，其中 ID 被输入管吸收，另 ID 经共栅管送到输出。
  2. 电流代价。同样的输入对电流，FC 的电源电流约为 telescopic 的 2 倍（4ID 对 2ID）。换来的是输出摆幅与输入共模范围，而不是免费的增益。
  3. 增益真相。基本 9 管 FC 的输出电阻是 Rup ∥ ro7。共栅支路的 Rup 很大，但被输出端简单电流源的 ro7 旁路，因此常常是 Av ≈ gm1ro7，只有 40–60 dB。要上 80–100 dB，必须做 gain boosting，或把输出电流源也 cascode 化。
  4. Headroom。输出高侧被 Vov5 + Vov3 吃掉，低侧被 Vov7 吃掉；输入共模低侧被 VTH + Vov1 + Vov,tail 限制。
  5. 极点。主极点在输出（1/RoutCL），非主极点在折叠节点（约 gm3/CX）。因为 CX 通常只有几百 fF，这个极点常在 GHz 量级，FC 因此接近单极点系统。
  6. 噪声。输入参考热噪声约为 (8kTγ/gm12)(gm1+gm3+gm5+gm7)。折叠源 gm5 = 2ID/Vov5，在同样 Vov 下比输入管高约 2 倍，是 FC 特有的噪声代价。
  7. 压摆。差分输出的 SR = ISS/CL；折叠节点也压摆，速度为 ID/CX，通常比输出快得多，但大尺寸共栅管可能让它变成限制项。
  8. 建立。建立时间必须拆成“压摆段 + 线性段”：ts ≈ ΔV/SR + τ ln(1/ε)，其中 τ = 1/(β·2π·GBW)。只用 GBW 估算会系统性乐观。
  9. 定尺寸。流程是“指标 → Gm/I/C → gm/ID、L → W/L”，不是“先给 Vov 再套平方律”。L 由 ro、Cgg、失配、1/f 共同决定。
  10. 案例量级。12-bit / 50 MS/s、CL = 2 pF、β = 0.5 的 SC MDAC：Gm ≈ 7 mS、ID ≈ 0.5 mA；基本 9 管 FC 约 55 dB，把输出电流源 cascode 化并把 L3 加到 0.72 µm 后约 92 dB，核心功耗约 3.6 mW；若目标 100 dB，再加约 20 dB booster。

这三条主线贯穿全文：架构选择决定“用什么换什么”，原理推导给出“换多少”的定量关系，定尺寸与迭代把这些关系落到 W/L、L、I 上。第 4 章的案例不是“标准答案”，而是一套可复现的算术：把假设换掉，流程仍然成立。

1结构与适用场景

“折叠共源共栅”不是单一电路，而是一族拓扑。它们共享同一个核心动作：把输入对产生的信号电流折叠到相反极性的共栅支路中，从而把输入级与输出级的电压余度解耦。不同的折叠方式、负载方式与增益增强方式，决定了这族电路在增益、摆幅、速度、噪声和功耗上的位置。本章先建立拓扑地图，再给出选型依据。

1.1 从 telescopic 到 folded：为什么多花一倍电流

理解 FC 最快的方式，是先看它要替代的 telescopic cascode。telescopic 把输入对直接堆叠在 cascode 支路上：电源到地一共四个 Vov 的堆叠（两个 PMOS、两个 NMOS），输出摆幅约为 VDD − 4Vov。它的优点是电流利用率高（总电流约 2ID）、输出电阻是两级 cascode 的乘积，因而在同样电流下增益最高。缺点是输出摆幅和输入共模范围被同时压缩，而且在低电源电压下，输入共模范围与输出摆幅可能没有交集，导致它不能直接接成单位增益缓冲器。

FC 的思路是把输入对从“堆叠”改成“并排”：输入对仍然放在底部（或顶部），但它的漏极不再直接串到输出，而是接到一个折叠节点 X；在 X 上，一个与输入对相反极性的电流源提供 2ID，一个同极性的共栅管把差值电流送往输出。这样，输入对只承受一个 VDS，输出支路也只承受共栅管与输出电流源的堆叠，输入与输出不再共享同一串电压余度。

图 1-1 是 NMOS 输入、PMOS 折叠的标准全差分 FC。先只看左半边。尾电流源 M0 把 2ID 从输入对抽走，因此 M1 的直流电流是 ID。折叠节点 X 上，PMOS 电流源 M5 提供 2ID；M1 吸收 ID，剩下的 ID 必须经 PMOS 共栅管 M3 流向输出。输出节点再接 NMOS 电流源 M7，它吸收 ID。直流 KCL 因此非常干净：

IM5 = 2ID,   IM3 = IM5 − IM1 = ID,   IM7 = ID
(1-1)

把两边合起来，电源电流是两路折叠源之和 4ID；输出支路的 ID 已经包含在这 4ID 里（它由折叠源经共栅管流到输出源，再回到地），不是额外的一路。对比 telescopic 的 2ID，这就是 FC 著名的“两倍电流代价”。

为什么必须让折叠源提供 2ID，而不是 ID？因为 X 节点同时要喂饱两个“吃电流”的支路：输入管 M1 和共栅管 M3。输入管的 ID 来自折叠源，共栅管的 ID 也来自折叠源；如果折叠源只有 ID，就没有电流送往输出了。这个“2 倍”不是浪费在电阻上，而是为了让输入级与输出级在电流上解耦。

常见误解：FC 的增益一定比 telescopic 低很多吗？

在相同电流、相同 L 下，基本 9 管 FC 的增益通常比 telescopic 低 20–30 dB，因为它的一条输出支路是简单电流源，Rout 被 ro7 旁路。但 FC 可以把输出电流源的 L 取得很长（它不承担速度），从而把 ro7 做大；代价是面积与 VDS,sat。如果再把输出电流源 cascode 化，FC 的增益可以接近 telescopic，但摆幅优势会被吃掉一部分。设计时要看的是“在给定摆幅与 CL 下，哪种结构的 Rout 更划算”，而不是抽象地比较拓扑。

1.2 全差分基本型与输入对的选择

图 1-1 画的是全差分、NMOS 输入、PMOS 折叠的版本。它是 SC 电路中最常见的形态，原因有三点：全差分抑制偶次谐波与共模干扰；输出不需要单端转换，避免镜像极点；输入共模可以做得较高，适合开关电容的 VDD/2 共模。代价是需要 CMFB（共模反馈），图 1-1 中没有画。

把输入对换成 PMOS，整个电路上下镜像：PMOS 输入对在上面，NMOS 折叠源在下面，NMOS 共栅管把电流送到输出，PMOS 输出电流源从 VDD 灌入输出。两种版本的直流电流关系完全对称，差别在输入共模范围、噪声与面积。

1.3 单端输出与电流镜负载

全差分 FC 有两个高阻输出，需要 CMFB，也需要两套反馈网络。很多单端 SC 电路、连续时间滤波器和片内稳压器更希望一个输出。此时可以把输出端的两个电流源换成一个电流镜：一侧二极管连接，把差分电流镜像到另一侧，在单端节点相加。图 1-2 是这个变体的示意。

电流镜负载的代价很具体：

  • 镜像极点。二极管连接节点的电阻约 1/gm7，电容是 Cgs7+Cgs8+Cdb，于是 ωp,m ≈ gm7/(Cgs7+Cgs8)。这个极点通常比折叠节点极点低，可能成为非主极点。
  • 噪声。镜像管 M7/M8 的噪声直接加在输出上，且 M7 的噪声被镜像到输出，输入参考噪声比全差分多一项。
  • 摆幅。单端输出仍然要在输出电流源上留一个 Vov，但少了一侧的共模反馈余度；实际可用摆幅通常比全差分少 0.1–0.2 V。
  • 系统失调。镜像电流的失配直接变成输入参考失调，需要 chopping 或 trimming 的场合要特别注意。

1.4 增益提高型（regulated cascode）

基本 FC 的增益瓶颈在输出端的简单电流源：Rout ≈ Rup ∥ ro7，而 ro7 通常远小于 Rup。要突破 80 dB，最直接的办法通常不是继续加长 L（面积与寄生电容不允许），而是让共栅管的栅极“动起来”：用一个辅助放大器 Ab 检测 X 的电压，驱动 M3 的栅极，使 X 的电压在输出变化时保持稳定。这就是 regulated cascode / gain boosting，如图 1-3。

直观理解：普通共栅管的栅极是固定的，输出端电压变化时，VSD3 变化，电流随之变化，等效输出电阻有限。加入 Ab 后，X 的电压被负反馈“钉住”，M3 的 VSG 随输出同步移动，M3 更像一个理想电流缓冲器，输出电阻提高约 (1+Ab) 倍：

Rout,boost ≈ (1+Ab) · gm3ro3(ro1 ∥ ro5)
(1-2)

注意：(1-2) 只提高 Rup。如果输出端的简单电流源 ro7 仍然与 Rup 并联且更小，总增益不会变；gain boosting 必须与输出电流源的 cascode 化（或足够大的 L7）配合。第 2.3 节与第 4 章会给出“加了 booster 但增益不涨”的具体例子。

代价是：多一个放大器、多一组偏置、多一个环路要稳定；Ab 的输入共模必须覆盖 X 的电压；Ab 的极点与主放大器的零点形成 doublet，可能在建立曲线上留下一条慢尾巴。Bult 与 Geelen 在 1990 年用这个结构在 1.6 µm CMOS 上做到了 90 dB 直流增益与 116 MHz 单位增益频率，是理解 gain boosting 的经典参考[1]。

1.5 Recycling folded cascode 与其它变体

基本 FC 有一个“电流效率”问题：输入对的 ID 在折叠节点被尾电流源抽走，只有共栅支路的那一份真正参与输出。RFC（recycling folded cascode）通过拆分输入管/共栅管，把一部分输入电流直接注入输出支路，使同样的总偏置下获得更高的等效 gm 与压摆率。Assaad 与 Silva-Martinez 的 JSSC 2009 论文报告了约 2 倍的 gm 与 SR 提升[2]；代价是输入电容、器件匹配与偏置拆分更复杂。

图 1-4 只画电流路径的概念，不画具体器件拆分。理解 RFC 的关键不是记住某个管子的接法，而是记住它的目标：让同一份偏置电流在输入与输出之间被“用两次”。因此它特别适合“电源电压不低、但功耗预算很紧、速度要求高”的场景。具体能提升多少，取决于电流分配比 k、输入管的拆分方式与版图匹配，不能简单套用“2 倍”。

其它值得知道的变体：

  • split-length / self-cascode：把长沟道管拆成两个短管串联，用偏置让它们工作在饱和区，等效于更长的 L，但占用更少的电压余度；代价是 ro 与匹配不如真正的长管。
  • class-AB / adaptive biasing：在大信号时临时提高尾电流或折叠电流，改善 SR；代价是线性度、静态功耗控制与 CMFB 复杂度。
  • bulk-driven / floating-gate：用于极低 VDD，但 gm 低、体漏电与工艺风险高，不适合作为默认选择。
  • chopping / auto-zeroing：降低 1/f 与失调，适合传感器前端；会引入 ripple 与时钟馈通，需要与 FC 的带宽一起设计。
  • source degeneration：在 CT 滤波器/线性化跨导中常用，用电阻或交叉耦合管降低失真，代价是 gm 与增益。

2原理与推导

这一章把 FC 拆成六个相互耦合的子问题：直流电流、电压余度、增益、极点、压摆、噪声。每个子问题都从饱和区的基本方程出发，给出近似条件与物理意义。公式中的“≈”不是偷懒，而是明确告诉读者：哪些二阶效应被忽略了，什么时候必须回到 SPICE。

2.1 直流工作点与电流预算

仍然以图 1-1 的 NMOS 输入、PMOS 折叠为例。设输入对单管电流为 ID，尾电流源 M0 提供 2ID。在折叠节点 X，M5 必须提供 2ID，因为 M1 吸走 ID，M3 还要把 ID 送往输出。输出节点由 M7 吸收 ID，与 M3 的电流相等。把所有支路加起来：

Isupply = IM5 + IM6 = 2ID + 2ID = 4ID
(2-1)

注意 IM7 = ID 并没有“额外”增加电源电流：它由 M5 经 M3 流过，已经包含在 2ID 里。这一点在手工做功耗预算时最容易多算一倍。若输入对电流为 0.5 mA，则总电源电流约 2 mA，核心功耗约 3.6 mW（VDD=1.8 V）。

各管的饱和条件给出电压余度的下限：

VX ≤ VDD − Vov5   （M5 饱和） VX ≥ VS1 + Vov1   （M1 饱和） Vout ≤ VX − Vov3   （M3 饱和） Vout ≥ Vov7   （M7 饱和）
(2-2)

把第一、三式合起来，就是输出高侧的上限 VDD−Vov5−Vov3；第四式给出低侧下限 Vov7。这就是为什么 FC 的输出摆幅是“高侧两个 Vov、低侧一个”。实际设计时，X 的电压由 M5 的偏置和 M3 的栅压共同决定，通常取在 VDD−Vov5 附近，以最大化输出高侧余度；但不能低到让 M1 退出饱和；X 的允许范围由 M5 与 M1 的饱和条件共同决定。

为什么 X 不是“输入共模减去 VTH”

很多初学者把 VX = VCM − VTH1 当成等式，其实那只是 M1 饱和的下限（VDS1=Vov1 的临界点）。真正的 X 由 PMOS 支路（M5 的电流与 M3 的栅偏置）决定，通常在高侧。设计时要验证的是“X 落在 M1 与 M5 都饱和的区间内”，而不是把 X 算成一个固定值。

输入共模上限的推导。M1 饱和要求 VDS1 = VX − VS ≥ Vov1。代入 VS 得 VCM ≤ VX + VTH1。而 VX ≤ VDD − Vov5，所以 VCM,max ≈ VDD − Vov5 + VTH1。因为 VTH1 通常大于 Vov5，这个值会超过 VDD；实际限制变成输入焊盘/ESD 或栅氧可靠性，而不是电路本身。这就是“NMOS 输入 FC 的共模可以到 VDD 附近”的原因。

PMOS 输入的对偶。把上面的 VGS 换成 VSG、VTH 取绝对值，得到 VCM,max = VDD − (VTH1+Vov1+Vov,tail)；低侧则接近 0。两条轨的余度是对偶的，选哪种输入对，本质上是在“靠近哪条轨”之间做选择。

Headroom 的三个隐藏项

(1) 体效应。输入管的源极不在地，VTH 随 VSB 上升，实际 VCM,min 比手算高 50–150 mV。(2) 共栅管的栅偏置。PMOS 共栅管的栅压不能低于 0 V，NMOS 共栅管的栅压不能高于 VDD；这会给 X 的允许范围加一条“偏置可实现性”约束。(3) 输出电流源的 VDS。M7 的 VDS=Vout，当输出接近地时，ro7 会下降，增益与线性度同时变差；摆幅下限不要贴着 Vov7 用。

2.3 小信号增益与输出电阻

先复习三个基本关系。强反型、忽略迁移率退化时：

gm = 2IDVov = √(2μCox(W/L)ID),    ro = VAID = 1λID

其中 VA = 1/λ 是 Early 电压，正比于 L（短沟道下还受漏致势垒降低影响）。gm/ID = 2/Vov 是强反型近似；在中等反型/弱反型，它趋向 1/(nVT) ≈ 20–25 V−1，这就是第 3 章 gm/ID 方法的入口。

输出电阻。图 2-2 是半边小信号模型。输出节点向上看进 M3 的漏极，向下看进 M7 的漏极。先算向上：M3 的源极接 X，X 对地的电阻是 ro1 ∥ ro5。对 M3 加测试电压 vt、测电流 it，源极电压 vs = it(ro1∥ro5)，且 vgs3 = −vs（栅极交流地）。KCL 给出：

(2-4)

解得

Rup = vtit = ro3 + RS + gm3ro3RS ≈ gm3ro3(ro1 ∥ ro5)
(2-5)

若考虑体效应，把 gm3 换成 gm3+gmb3 = gm3(1+η)，η≈0.1–0.3。Rup 因此比手算再高 10–30%。在 9 管基本型中它通常不是瓶颈；一旦输出电流源也 cascode 化，Rup 就会成为主要限制项。

向下看，M7 是简单电流源，Rdown = ro7。于是

Rout = Rup ∥ ro7 = Rupro7Rup + ro7,    Av = GmRout ≈ gm1(Rup ∥ ro7)
(2-6)

信号路径。可以把 FC 的信号路径分成三段：输入对把差分电压变成电流（gm1vid）；折叠节点 X 把这一电流“折”进共栅支路（共栅管源极的 1/gm3 很低，电流几乎全部流入 M3）；共栅管再把电流送到输出高阻节点，由 Rout 转成电压。理解这三段，就能理解为什么 Gm≈gm1、为什么 X 的电压对增益不敏感、以及为什么 Rout 是增益的瓶颈。

这里 Gm ≈ gm1 的推导：差分输入 vid = vin+−vin− 使 M1/M2 的电流各变化 ±gm1vid/2；折叠节点把这一电流传到共栅支路，输出端得到 ±gm1vid/2 的电流变化；差分输出电流为两者之差，即 gm1vid。因此 Gm=gm1，因子 2 已经在“差分”里。

最容易被忽略的一句话

在基本 9 管 FC 中，共栅支路的高输出电阻是被浪费的。因为输出节点同时挂着 M7 的 ro7，而 ro7 通常远小于 Rup，所以 Rout≈ro7，Av≈gm1ro7。这不是“cascode 没起作用”，而是“cascode 的电流缓冲作用被一个低阻负载旁路了”。要提高增益，先问“谁是 Rout 的限制项”，再决定加长 L、cascode 化输出源，还是加 booster。

2.4 极点、零点、GBW 与相位裕度

FC 是单级结构，没有 Miller 补偿电容，频率响应主要由两个节点决定：输出节点（大电容、大电阻）与折叠节点 X（小电容、小电阻）。写出二极点模型：

A(s) = A0(1+s/ωp1)(1+s/ωp2),    A0 = GmRout
(2-7)

主极点。输出节点的电阻是 Rout，电容是 CL（含负载、反馈网络、下一级输入与版图寄生）：

ωp1 = 1RoutCL,    GBW = A0ωp1 = GmCL   （当 ωp2 ≫ GBW）

这就是“GBW 只由 Gm 和 CL 决定”的来源。注意它成立的前提是 ωp2 ≫ GBW；如果非主极点离 GBW 很近，实际 −3 dB 带宽与单位增益频率都会被拉低。

非主极点。折叠节点 X 向上看是 M5 的 ro5，向下看是 M1 的 ro1，向右看是 M3 的源极阻抗 ≈1/gm3。三者并联，最小的是 1/gm3（通常几十到几百欧），所以

  • 电流镜负载的镜像极点。ωp,m≈gm7/(Cgs7+Cgs8)，通常比 ωp2 低，是单端 FC 的主要非主极点。
  • gain-boosting 的 doublet。booster 的极点与主路的零点形成一对接近的极点/零点，会在建立曲线上留下慢尾巴；见 2.9。
  • 输入网络的极点。在 SC 电路中，采样开关的 Ron 与 OTA 的 Cin 形成极点；它可能限制采样精度，而不是 OTA 本身。

2.5 压摆率与内部节点限制

大信号时，输入对差分电压足够大，一侧输入管几乎关断，尾电流全部转向另一侧。此时输出电流达到最大值。对图 1-1 的左半边：M5 固定提供 2ID；M1 关断时，M3 的电流升到 2ID；M7 固定吸收 ID，所以输出净充电电流为 +ID。另一边相反，输出净放电电流为 −ID。差分输出电流为 2ID=ISS，于是

SR = ISSCL = 2IDCL
(2-11)

这个式子假设共栅管能提供 2ID。实际上 M3 的栅压是固定的，它的最大电流由 VSG3 与 W/L 决定；如果 M3 只按 ID 设计，过驱动余度不够，正压摆会先受限。设计时要让 M3 在 2ID 下仍能保持饱和，或者接受正负压摆不对称。

折叠节点压摆。X 节点的电容 CX 由 M5 的 2ID 与 M3 的电流差充电。最坏情况下，M3 电流从 ID 变到 2ID，差值只有 ID，所以

SRX ≈ IDCX
(2-12)

以 ID=0.5 mA、CX=250 fF 为例，SRX≈2 V/ns=2000 V/µs，远高于输出的 500 V/µs；本案例的 CX≈682 fF，SRX≈730 V/µs，仍高于输出 SR，但余量已经不大。所以正常情况下 X 不是压摆瓶颈；但如果为了增益把 M3 做得很大，CX 上升，SRX 可能降到与输出 SR 同一量级。此时建立曲线会出现“两段压摆”，仿真中表现为先快后慢的折点。

尾节点与共模压摆。尾电流源的寄生电容、输入对的源极电容与 CMFB 环路共同决定共模压摆。差分信号下尾节点是虚地，影响小；共模阶跃时，尾电流源的有限输出电阻与 CMFB 的带宽会让共模建立变慢。SC 电路中，共模与差模同时建立，CMFB 不能成为最慢的环。

2.6 建立过程：压摆 + 线性

单位增益反馈下，单极点 OTA 的闭环误差按 e−t/τ 衰减，其中

τ = 1βωu = CLβGm
(2-13)

推导很直接：闭环环路增益为 βA(s)，在 βA0≫1 时，闭环极点位于 βωu。若误差从 ΔV 开始，要求最终误差小于 ε，则

tlin = τ ln(ΔVε) ≈ τ ln(1εr)
(2-14)

对 N 位精度，若满量程为 FS、允许误差为 0.5 LSB = FS/2N+1，则相对误差 εr=1/2N+1，tlin=(N+1)ln2·τ≈0.693(N+1)τ。12 位对应约 9τ，10 位约 7.6τ，14 位约 10.4τ。

ts ≈ ΔVSR + τ ln(ΔVlinε),    ΔVlin ≈ ΔV − SR·tslew
(2-15)

2.7 噪声：热噪声、1/f 与折叠支路代价

MOS 的沟道热噪声电流为 in2=4kTγgmΔf，栅极参考电压噪声为 vn2=4kTγ/gm·Δf。把每个器件的噪声电流除以其到输出的传递函数，再除以 Gm2，就得到输入参考噪声。对图 1-1 的 FC：

vn,in2 = 8kTγgm12(gm1 + gm3 + gm5 + gm7)
(2-16)

逐项解释：

  • M1/M2（输入对）：两管各贡献 4kTγgm1，除以 gm12 得 8kTγ/gm1。这是“不可再降”的底噪，除非加大 gm1 或降低 γ。
  • M3/M4（共栅）：噪声电流直接出现在输出端，两管贡献 8kTγgm3/gm12。共栅管的 gm3 通常比 gm1 小，但不可忽略。
  • M5/M6（折叠源）：在 X 点，噪声电流看到 1/gm3 与 ro1 的并联；前者远小，所以大部分噪声电流流入 M3，再以约 1 的电流增益到输出。贡献也是 8kTγgm5/gm12。
  • M7/M8（输出源）：噪声电流直接注入输出节点，贡献 8kTγgm7/gm12。若 M7 下面再串 M9（cascode 输出源），M9 的噪声也会经 M7 到输出，需再加 8kTγgm9/gm12。

把 gm=2ID/Vov 代入，可以看到 FC 特有的问题：折叠源 M5 的电流是 2ID，在同样 Vov 下 gm5=2gm1，它的噪声功率贡献可能是输入对的 2 倍。要压低它，只能提高 Vov5（牺牲 headroom）或增大 L（牺牲面积/寄生），这就是“噪声—摆幅—功耗三角”的具体来源。

图 4-1 是第 4 章案例的噪声贡献分解：输入对 24%、共栅 17%、折叠源 16%、输出 cascode 23%、输出源 19%。折叠源不是最大项，但它是 FC 相对于 telescopic 多出来的那一项；如果 Vov5 从 0.22 V 降到 0.15 V，gm5 会从 4.55 mS 升到 6.67 mS，其贡献从 16% 升到约 22%，总噪声上升约 4%。

1/f 噪声。输入参考 1/f 噪声可写成 vn,1/f2 ≈ Kf/(CoxWL·f)（不同工艺的 Kf 定义不同，量纲也不同）。它与面积成反比，因此低 1/f 设计要加大 W·L，这会增加 Cin 与 Cgs。PMOS 的 Kf 通常比 NMOS 小，所以低 1/f 前端常用 PMOS 输入；代价是面积更大、gm/W 更低。斩波可以把 1/f 搬到高频，但会引入 ripple 与时钟馈通。

总积分噪声。把输入参考噪声密度在闭环噪声带宽上积分。对一阶闭环，等效噪声带宽为 (π/2)β·GBW，于是

vn,rms ≈ vn,density·√(π2β·GBW)
(2-17)

SC 电路还要加上采样电容的 kT/C 噪声。两者独立，按功率相加：vn,total2=vn,OTA2+kT/Cs。当 OTA 噪声与 kT/C 相当时，继续加大 OTA 电流的收益递减；这时应该加大采样电容，而不是无脑加 gm。

噪声公式的适用条件

(2-16) 假设：所有器件工作在饱和区；γ 为常数；共栅管的噪声传递为 1；尾电流源的噪声对差模输出可忽略（它主要影响共模/CMRR）；ro 足够大。短沟道下 γ 可能大于 1，共栅管的噪声传递也会因 ro 有限而略小于 1；精确设计要用 SPICE 的 noise 分析，并区分热噪声与 flicker 噪声的积分带宽。

2.8 线性度、CMFB 与电源抑制

线性度。FC 的失真主要来自三处：输入对的 gm 非线性（Vov 越小、摆幅越大，失真越明显）；共栅管在输出摆幅边缘进入线性区；输出电流源在 VDS 较小时 ro 下降。前两项可以通过增大 Vov、减小信号摆幅、或源极退化来改善；第三项靠留足 VDS 余度。FC 本身没有 Miller 补偿，因此没有两级运放那种“补偿电容非线性”问题，这是它在 SC 电路中的额外优点。

CMFB。全差分 FC 的输出共模是高阻节点，必须用 CMFB 锁定。常见做法是用电阻或电容分压检测 Vout+ 与 Vout−，与 VCM,ref 比较，误差经 CMFB 放大器控制尾电流源或折叠电流源。控制尾电流会同时改变输入对电流与输出共模，环路增益较高；控制折叠源会直接改变输出共模，但会调制 gm5 与噪声。无论哪种，CMFB 的带宽要高于差模环路的单位增益频率，否则共模与差模会相互牵制；但 CMFB 太快会把电源噪声注入输出，需要折中。

PSRR / CMRR。电源噪声主要通过折叠源 M5/M6 与输出源 M7/M8 耦合到输出。共栅管对电源噪声有一定的屏蔽作用，但 M5 的 ro5 与 M3 的 gm3 形成分压，频率越高，Cgs3 的馈通越明显。提高 PSRR 的办法包括：给偏置加去耦、把折叠源做成 cascode、让 CMFB 的检测网络对电源对称。CMRR 主要受尾电流源的输出电阻与输入对失配限制；尾管越长、ro0 越大，CMRR 越好。

2.9 增益提高环路的稳定性与 doublet

gain boosting 是一个嵌套环路：主放大器提供主信号路径，booster 在局部把 X 的电压钉住。分析稳定性时，把主放大器的输入置零，断开 booster 的环路，看环路增益 Tb(s)。这个环路里有两个关键极点：booster 输出（M3 栅极）的极点，以及 X 节点的极点 gm3/CX。稳定条件可以粗略写成

fu,b < 12π·gm3CX = fp,X
(2-18)

并且 booster 自身的相位裕度要大于 60°。如果 fu,b 太接近 fp,X，局部环路会振铃，表现为输出建立时的过冲或持续振荡；如果 fu,b 太低，booster 来不及响应，增益提高在 GBW 附近失效，直流增益虽然高，但闭环建立会变慢。

Doublet。闭环增益中会出现一对接近的极点/零点，位置大约在 fu,b 附近。若极点与零点完全重合，它们互相抵消；若失配，残差会在阶跃响应上形成一条幅度约 1/Ab、时间常数约 1/(2πfu,b) 的慢尾巴。对 12 位建立，这条尾巴可能比主极点的时间常数更长，是 gain boosting 最隐蔽的风险。对策：让 fu,b 至少是主 GBW 的 2–3 倍；用前馈路径制造一个与极点匹配的零点；在版图上让 booster 与主路的寄生对称。

booster 的输入/输出共模。booster 检测 X，输出驱动 M3 栅极。X 的共模取决于输入对极性（见 1.2）；M3 栅极的共模由 cascode 的偏置决定。两者都必须落在 booster 的输入/输出共模范围内，否则 booster 的增益下降、失调变大，甚至锁死。设计时先把 X 与 VG3 的标称值算出来，再选 booster 的输入对极性，不要反过来。

本章的可操作结论

FC 的设计可以拆成四个“先看谁”的顺序：先看 headroom（决定 Vov 的上限）→ 再看增益瓶颈（是 ro7 还是 Rup）→ 再看非主极点（CX 是否把 fp2 拉到 GBW 附近）→ 最后看噪声与压摆（它们决定电流与 Vov 的最终取值）。顺序反过来，很容易在“增益不够就加电流”的循环里打转。

3.2 gm/ID 方法：为什么用它、怎么用

平方律把晶体管分成“强反型”和“不工作”两态，但现代模拟设计大量工作在中等反型：Vov 只有 50–150 mV，gm/ID 既不是 2/Vov 的强反型值，也不是弱反型的指数值。gm/ID 方法用一条从弱反型到强反型的连续曲线描述器件，把“工艺参数”和“设计选择”分开：

gmID = 2Vov  (强反型),    gmID → 1nVT ≈ 20–25 V−1  (弱反型)
(3-1)

归一化电流（inversion coefficient）常写成

IC = ID2nμCoxVT2(W/L)
(3-2)

IC≪1 是弱反型，IC≫1 是强反型，IC≈0.1–10 是中等反型。gm/ID 曲线与 IC 一一对应，因此只要知道“我想要多大的 gm/ID”，就能查出 Vov、fT、Cgg/(WL) 等归一化量，再乘 W/L 得到实际值。

3.3 逐步定尺寸流程

  1. 算 Gm 与 ID。从 GBW 与 CL 得 Gm=2π·GBW·CL；基本 FC 中 gm1=Gm。选 gm/ID（噪声/功耗折中），得 ID=gm1/(gm/ID)。用 SR 反算 ISS=SR·CL，若 2ID<ISS，说明压摆更紧，取大者。
  2. 定 Vov 的初值。输入对 0.1–0.2 V；折叠源 0.2–0.3 V；共栅 0.1–0.15 V；输出源 0.15–0.25 V；尾管 0.1–0.15 V。先把所有 Vov 相加，检查是否仍在 headroom 内；不够就降折叠源或输出源的 Vov，并接受噪声/增益的代价。
  3. 选 L。按表 3-2。输入对与共栅取短 L；输出源与折叠源取中/长 L；尾管中/长。若增益不够：输出源是简单电流源时，先加 L7（Rout 被 ro7 限制）；输出源已经 cascode 化时，再按 Rup 与 Rdown 谁是瓶颈选择 L3/L7/L9，不要盲目只加 L3。
  4. 算 W/L。用 W/L=2ID/(μCoxVov2) 做初值；若有 PDK 的 gm/ID 表，直接查 W/L。注意 PMOS 的 μCox 低，同样 ID 与 Vov 下 W 大 3–4 倍。

  1. 增益与摆幅的冲突。提高增益最有效的手段（cascode 输出源、增大 L 以提高 ro、加 booster）往往同时吃掉 headroom 或增加面积。先问“摆幅能不能让”，再问“增益要不要那么高”。
  2. 噪声与功耗的冲突。降低热噪声要加 gm1，在固定 gm/ID 下就是加电流；降低 1/f 要加面积。两者都会增加 Cin/Cgs，反过来影响速度。
  3. 速度与稳定的冲突。提高 GBW 可以加 Gm 或减 CL；但 CX 不变时，GBW 上升会逼近 fp2，PM 下降。高速设计往往不是“加电流”，而是“重新分配 CX 与 CL”。

3.6 版图、匹配与寄生

FC 的版图不是“把原理图连起来”。以下几个节点/器件需要特别处理：

  • 输入对与尾管：共质心、同方向、加 dummy；尾管与输入对的源极节点要低阻、对称。输入对之间的 VTH 失配直接变成输入失调，按 Pelgrom 规律 σVTH∝1/√(WL) 用面积换匹配。
  • 折叠节点 X：这是高阻、小电容节点，CX 每增加 100 fF，fp2 就下降一截。M1、M5、M3 的漏极/源极电容都挂在这里，版图上要尽量短、避免跨线、避免在 X 上方走大金属。
  • 输出节点：CL 含反馈电容、下一级输入、Pad/ESD 与金属寄生。做 AC 仿真时不要把 CL 只设成理想电容；把反馈网络与开关寄生一起提出来。
  • 共栅管栅极：偏置线要低阻，必要时加去耦电容；不要把长偏置线当成理想电压源，它会和 Cg3 形成极点。
  • 电源/地：折叠源与输出源对电源噪声敏感；用独立的模拟电源、星形接地、guard ring。全差分对共模噪声有抑制，但电源噪声会通过 ro 与 Cgd 耦合，不能只靠“差分”二字。
  • CMFB：检测网络要对称，检测点尽量靠近输出；CMFB 放大器的输入对要匹配，否则输出共模有系统误差。

4.2 架构选择

第一步：排除 telescopic。telescopic 的输出摆幅约 VDD−4Vov。按每管 0.2 V 估算，只有 1.0 V，恰好等于本案例的 1.0 Vpp,diff，没有任何 corner 余量；而且输入共模低侧被尾管顶住，0.88 V 的共模在慢 corner 下容易越界。因此选 FC。

架构选择的结论

选全差分、NMOS 输入、PMOS 折叠、输出电流源 cascode 化的 11 管 FC；L3=L7=L9=0.72 µm；不加 booster，先看 91.8 dB 是否够。若系统要求 100 dB，或 CL 变大导致 PM 不够，再考虑 20 dB booster + 短 L3 的方案（见 4.5）。

为什么选 NMOS 输入而不是 PMOS？本案例的共模 0.88 V，NMOS 输入的共模下限约 0.74 V，余度 0.14 V；PMOS 输入的共模上限约 1.8−(0.45+0.143+0.15)=1.06 V，余度 0.18 V，反而更宽。但 PMOS 的 μ 低，同样 gm 下 W 约大 3.75 倍，Cin 与面积都上去；50 MS/s 下 1/f 不是主要噪声，所以选 NMOS。如果这是一颗低 1/f 的传感器前端，应该反过来选 PMOS，并接受更大的输入电容。

输出摆幅不够Vov5/Vov7/Vov9 太大；共模偏高降 Vov5 或 Vov9；降 VCMW5 变大、gm5 变大（噪声↑）；降共模会吃输入共模下限

4.5.1 方案 A：不加 booster，把 L3 加到 0.72（本案例采用）

结果就是 4.3 节的 91.8 dB / PM 64.5°。优点是结构简单、没有 doublet、没有 booster 的偏置共模问题；缺点是 CX 大、PM 余量小、面积大。如果系统只要 90 dB，这是最省心的方案。

4.5.2 方案 B：20 dB booster + 短 L3

把 L3 退回 0.36（CX≈250 fF，fp2≈3.18 GHz，PM≈80°），在 M3 的栅极加一个 20 dB 的 booster。此时 Rup 被提高 (1+Ab)=11 倍，Rup≈35.3 MΩ，与 Rdown=41.8 MΩ 并联得 Rout≈19.2 MΩ，A0≈102.6 dB。对比：

4.5.3 如果 CL 变大

SC 电路的 CL 往往在提取后比手算大 20%–30%。若 CL=2.6 pF：

  • GBW 从 557 MHz 降到 428 MHz，τ 从 571 ps 升到 743 ps；若 ISS 不变，SR 仍是 500 V/µs，tslew 不变，线性段只剩 6 ns/743 ps=8.1τ，误差 0.30‰=300 ppm，超标。
  • 对策：把 ID 加到 0.6 mA（Gm=8.4 mS，GBW 回到 514 MHz，SR≈460 V/µs），功耗到 4.3 mW；或者把 Cs 降到 0.8 pF（噪声↑）。
  • 这就是为什么 CL 的提取要在 schematic 阶段做一次、版图后再做一次，不能只用理想 2 pF。

4.6 结果讨论与下一步

哪些结论可信？趋势与量级：2× 电流代价、Rout 被输出支路限制、CX 与 PM 的反向关系、噪声随 gm 的下降、headroom 的逐层扣除。这些不依赖具体工艺，换一个 PDK 仍然成立。

哪些结论不可信？绝对数值：91.8 dB、1.17 GHz、64.5°、77.2 µV，全部建立在表 4-2 的假设上。真实 PDK 的 VA 可能只有假设的一半，Cdb 可能大 50%，γ 可能到 1.2；任何一个都会让结果偏移 10%–30%。所以这些数字只能用来“定方向、定初值”，不能用来“签核”。

下一步（按优先级）：

  1. 换 PDK。用实际工艺的 gm/ID 表重算 W/L；用 DC 工作点提取 gm、gds、Cgg、Cdd，回填表 4-6。
  2. 提寄生。把 CX、CL、偏置网络的电容从版图提取；重跑 AC/STB，确认 PM。
  3. 跑 corner。SS/FF/SF/FS、−40/25/125 °C、VDD±10%；最坏 corner 下增益/GBW/PM/摆幅是否仍达标。
  4. 跑瞬态。用实际 SC 时钟、开关电阻、共模阶跃；看建立曲线有没有 doublet 尾巴、CMFB 振铃。
  5. 跑噪声与 MC。区分热噪声/1/f，积分到实际带宽；MC 看失调与良率。若噪声超标，按 4.5.2 的方案 B 或加 ID。
  6. 决定是否加 booster。如果 91.8 dB 够用，保持方案 A；如果系统要 100 dB 或 PM 余量不足，转到方案 B，并按 2.9 节检查 doublet 与局部环路稳定性。
这个案例最容易踩的三个坑

(1) 把 91.8 dB 当成仿真结果。它只是 gm1(Rup∥Rdown) 的手算值，VA 与 Cdb 都是假设。(2) 忘了 M9/M10 的噪声与 Vov。cascode 输出源提高增益，但多一组噪声、多一个低侧 Vov，摆幅与噪声都要重算。(3) 把 CX 只算成 Cgs3。版图后的 Cdb、走线、偏置网络可能再贡献 100–200 fF，足以把 PM 从 64.5° 拉到 58°。

5.2 检查清单

下面 30 条按“规格 → 架构 → DC → AC → 瞬态/噪声 → 版图/签核”分组。每条后面的小字是“为什么值得检查”，不是形式主义。签核时逐条打勾；任何一条“未验证”都要写进风险清单。

A. 规格与预算（1–5）

  • CL 是否包含反馈网络、开关、下一级输入与 Pad/ESD？只填理想电容会把 GBW 高估 20%–40%，建立时间在硅上直接超标。
  • β 是否取了最坏相位/最坏负载？SC 电路的 β 随开关相位变化；闭环极点 βωu 跟着变。
  • 建立误差是否按“压摆 + 线性”两段算？只用 9τ 会忽略压摆段，尤其是大阶跃/大 CL。
  • 噪声预算是否含 kT/C 与后级贡献？OTA 噪声与采样噪声通常同量级，只算一项会低估总噪声。
  • 功耗预算是否含 CMFB、偏置、booster？辅助电路常占 5%–15%，低功耗设计里不能忽略。

B. 架构（6–10）

  • 输出摆幅是否覆盖 Vout,max/Vout,min 的 corner？headroom 是“减法”，corner 下 Vov 会变大。
  • 输入共模是否落在 VCM,min/VCM,max 内并留余量？NMOS/PMOS 输入对的选择本质上是共模范围的选择。
  • 增益目标是 90 dB 还是 100 dB？输出支路是否 cascode？9 管 FC 的 Rout 被 ro7 限制，单靠加 L7 有上限。
  • 单端还是差分？是否需要 CMFB？电流镜负载省 CMFB，但引入镜像极点与噪声。
  • 如果加 booster，它的输入/输出共模是否覆盖 X 与 VG3？NMOS 输入 FC 的 X 在高侧，PMOS 输入的 X 在低侧；选错极性 booster 不工作。

C. DC 工作点（11–15）

  • 所有管在 TT/SS/FF 下都有 VDS−VDS,sat≥50 mV？50 mV 是经验余量；小于 20 mV 时 ro 与失配都会恶化。
  • 折叠节点 X 是否落在设计值附近，且没有把 M1/M5 推出饱和？X 由 PMOS 支路决定，不是“VCM−VTH”的等式。
  • 输出共模是否被 CMFB 锁在目标值？CMFB 检测点是否正确？检测点错了，CMFB 会把差模也当成共模调。
  • 偏置电流是否与手算一致？有没有多算/少算 2ID？折叠源 2×、输出源 1×，总电源电流是 4×。
  • 启动/使能时所有节点是否能建立？高阻节点 + 零电流启动可能锁死；需要启动电路或复位。

D. AC 与稳定性（16–20）

  • A0、GBW、PM 是否在最坏 corner 下仍达标？TT 的 PM 65° 在 SS 可能只有 55°。
  • 非主极点 fp2 是否 ≥ 2×GBW？低于 1.73× 时 PM < 60°；低于 1× 时可能振荡。
  • 共栅管栅极偏置网络是否引入 GBW 附近的极点？RbiasCg3 可能把 PM 拉低。
  • CMFB 环路与 booster 环路的 PM 是否独立验证？差模 PM 好，不代表共模/局部环路稳定。
  • 增益提高的 doublet 是否落在建立误差带之外？doublet 的慢尾巴可能比主极点更长。

E. 瞬态与噪声（21–25）

  • 正/负压摆是否对称？M3 能否提供 2ID？栅压固定的共栅管在大信号时可能先限流。
  • 建立曲线是否有过冲、振铃或双斜率？双斜率通常意味着折叠节点或 CMFB 在压摆。
  • 输入参考噪声是否分热噪声/1/f 积分？带宽是否用闭环带宽？用开环 GBW 积分会高估；用错带宽会低估。
  • kT/C 是否按实际采样电容与寄生计算？采样电容通常比手算小 10%–20%（寄生）。
  • 共模阶跃时输出是否保持在 CMFB 的捕获范围内？SC 复位/采样切换会产生共模阶跃。

F. 版图与签核（26–30）

  • 输入对/尾管/镜像管是否共质心、同方向、加 dummy？失配直接变失调；系统失调可能吃掉半条误差预算。
  • 折叠节点 X 的走线是否短、寄生是否已提取？CX 每加 100 fF，PM 可能掉几度。
  • 后仿的 CL、CX、偏置电容是否回填到 AC/瞬态？原理图与版图的 CX 差 2× 很常见。
  • PSRR/CMRR 是否在 1 kHz–10 MHz 范围内扫过？低频 PSRR 好不代表高频好；折叠源与 CMFB 会把电源噪声带到输出。
  • MC 的增益/PM/失调良率是否达标？TT 仿真通过不等于可量产；失配与工艺漂移要统计。

附录 B　常见错误与排查

  1. 把折叠源的 2ID 算成 ID。症状：功耗预算偏低、M5 的 W 偏小、噪声仿真比手算高。排查：在 X 点写 KCL，确认 M5 同时供 M1 与 M3。
  2. 以为 gain boosting 一定能把增益拉上去。症状：加了 booster，直流增益几乎不变。原因：ro7 仍是瓶颈，(1+Ab)Rup∥ro7≈ro7。排查：先看 Rdown 是否已 cascode 化，再决定 booster 加在哪一侧。
  3. 忽略 CX 的版图寄生。症状：原理图 PM 70°，后仿 55°。排查：单独提取 X 节点的 Cdb/走线电容；把 Cgs3 与 Cdb5 分开列。
  4. 只用 GBW 估建立。症状：仿真建立比手算慢一倍。原因：压摆段、CMFB、doublet 都没算。排查：按 (2-15) 两段预算，并在瞬态里看斜率。
  5. 忽略体效应。症状：VCM,min 比手算高 100 mV，慢 corner 下尾管进线性。排查：在 DC 工作点看 VTH 的实际值，不要用标称值。
  6. CMFB 环路没有独立验证。症状：差模 AC 很好，瞬态共模振铃。排查：跑 CMFB 的 STB，确认 PM 与带宽；检测网络要对称。
  7. 把“典型 0.18 µm 参数”当成 PDK。症状：手算与仿真差 30% 以上。排查：用 PDK 的 gm/ID 表与 VA 数据回填；所有假设写进文档。
  8. cascode 输出源忘了噪声与 Vov。症状：增益达标，噪声/摆幅超标。排查：把 M9 的 gm9 加进 (2-16)，把 Vov9 加进低侧 headroom。
  9. booster 的输入共模选错。症状：booster 输出饱和，增益提高失效。排查：先算 X 的标称电压；NMOS 输入 FC 的 X 在高侧，PMOS 输入的 X 在低侧。
  10. 用理想 CL 做 AC，用理想时钟做瞬态。症状：仿真通过，硅上失败。排查：把开关电阻、寄生电容、时钟非重叠、共模阶跃都加进去；后仿再跑一遍。
最后一句

折叠共源共栅的“难”不在于记住 9 个管子怎么接，而在于同时管住四个互相拉扯的量：输出电阻、折叠节点电容、headroom、噪声。本文的所有公式、表格与案例，都是为了让你在改一个管子之前，先知道它会拉动哪三个指标。真正签核时，仍然要回到 PDK、SPICE 与版图；但有了这套手算骨架，仿真结果偏离时你能很快判断“是模型的问题，还是设计的问题”。
